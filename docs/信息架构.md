# 化龙幼儿园 · 管理端控制台 信息架构

> 面向幼儿园管理者（园长 / 各部门负责人）的 PC 端数据管理后台。
> 原型形态：单文件 `index.html`，左侧固定导航 + 右侧多视图切换。
> 本文档用于团队内部分享，Mermaid 流程图可在支持 Mermaid 的编辑器（VS Code、语雀、飞书、GitHub）中直接渲染。

## 四、资源与案例（内容库管理）

```mermaid
flowchart LR
    Library["资源与案例"]

    Library --> LibFilter["筛选与搜索"]
    LibFilter --> LF1["类型：资源 / 案例"]
    LibFilter --> LF2["分类：衣 / 食 / 住 / 行 / 艺"]
    LibFilter --> LF3["年级：小班 / 中班 / 大班 / 通用"]
    LibFilter --> LF4["学期时间窗口：园所学期日历"]
    LibFilter --> LF5["状态：已发布 / 待审核 / 已下架"]
    LibFilter --> LF6["名称搜索"]

    Library --> Coverage["教师首页推荐覆盖<br/>小班 / 中班 / 大班各 0—3 条"]
    Library --> LibTable["内容列表<br/>名称 · 类型 · 分类 · 年级 · 上传人 · 提交时间 · 浏览量 · 状态 · 推荐"]
    LibTable --> LibSort["点击任一资料列名切换升 / 降序<br/>仅当前页面会话，不写数据库"]
    LibTable --> LibRec["推荐 → 推送至教师端首页"]
    LibTable --> LibShelf["上架 / 下架"]
    LibTable --> LibPreview["预览"]
```

学期筛选读取后端 `db_school_term.start_date/end_date`，以资源／案例的 `created_at` 形成查询窗口；不按固定月份猜测园所学期。推荐覆盖率使用与教师首页相同的年级、审核状态与可见条件，且不受当前表格筛选影响。教师首页同年级三条的自动稳定顺序仍是 `USER-JOURNEY.md` Q55-b1 开放项；管理表格的本地排序不得写入 `db_home_case.display_order`。

## 十、成长册设置

园所统一配置成长册的公共内容，发布后分发给各班教师填充班级内容。**美术设计不在此处** —— 边框、底纹、版式属于我们提供的模板，园所只填占位符。

```mermaid
flowchart LR
    GrowthBook["成长册设置"]

    GrowthBook --> Tpl["选用模板"]
    Tpl --> TplNote["1-2 套封面 + 内页模板<br/>版式 / 边框 / 底纹由模板决定"]
    Tpl --> TplLock["定稿后锁定，需先撤回才能更换"]

    GrowthBook --> Assets["园所素材"]
    Assets --> A1["园所 Logo"]
    Assets --> A2["封面照片"]
    Assets --> A3["封面标题文字<br/>留空取园所名称"]

    GrowthBook --> Intro["园所介绍<br/>预设第 1 栏正文 · 发布前必填"]

    GrowthBook --> Msg["园长寄语"]
    Msg --> M1["通用"]
    Msg --> M2["小班 / 中班 / 大班<br/>留空则回落通用"]
    Msg --> M3["教师端按班级年级自动取用"]

    GrowthBook --> Sec["园所栏目（新增）"]
    Sec --> S1["选栏目版式<br/>纯文字 / 上图下文 / 两图并排 / 整页大图"]
    Sec --> S2["填标题 · 正文 · 照片"]
    Sec --> S3["插入位置<br/>可锚到预设项或另一个园所栏目"]
    Sec --> S4["下发后教师端只读<br/>不征集 · 不逐班不同"]

    GrowthBook --> Preview["预览<br/>填写区旁即时预览 + 整册预览"]

    GrowthBook --> Publish["草稿 / 已发布"]
    Publish --> P1["发布 → 各班教师收到模板"]
    Publish --> P2["未发布 → 全园成长册不可生成"]
    Publish --> P3["撤回 → 只停止分发<br/>不删除班级已填内容"]
```

> **不做的事**：按年级下发新增栏目。「入学第一天」「最后一天」逐班不同，归班级教师自行新增；园所若要给毕业班统一致辞，走园长寄语的年级变体。
>
> **园所栏目 vs 班级栏目**：园所栏目由园所填定后直接下发，全园每本册子内容相同、教师端只读、不向家长征集；班级栏目由教师新增、可自由排版、可向家长征集素材。两者版式都由我们提供或由教师在网格上排，园所不上传美术素材。

## 十一、与教师端 / 家长端的数据联动

管理端不是孤立后台，多数操作会作用到前端（教师端小程序、家长端）。

```mermaid
flowchart TB
    subgraph TeacherApp["教师端"]
        T_Upload["上传资源 / 案例"]
        T_Profile["教研培训 → 个人档案修改"]
        T_Feedback["历史研修 → 研修反馈"]
        T_Todo["待办任务"]
        T_Home["首页推荐"]
        T_Column["资讯栏目<br/>党建 / 通知 / 教研"]
        T_Book["成长册编辑<br/>班级内容填充 + 新增栏目"]
    end

    subgraph AdminConsole["管理端控制台"]
        A_Review["审核中心"]
        A_Library["资源与案例"]
        A_Tasks["任务管理"]
        A_Content["内容发布"]
        A_GrowthBook["成长册设置"]
        A_Data["数据看板 / 测评 / 家园共育"]
    end

    T_Upload -->|提交审核| A_Review
    T_Profile -->|提交审核| A_Review
    T_Feedback -->|提交审核| A_Review

    A_Review -->|通过入库| A_Library
    A_Library -->|推荐| T_Home
    A_Tasks -->|发布| T_Todo
    A_Content -->|发布| T_Column
    A_GrowthBook -->|发布后分发模板<br/>封面 · 园所介绍 · 园长寄语| T_Book
    A_Review -->|反馈通过| T_Feedback

    T_Upload -.统计.-> A_Data
```
