# 化龙幼儿园 · 管理端控制台 信息架构

> 面向幼儿园管理者（园长 / 各部门负责人）的 PC 端数据管理后台。
> 原型形态：单文件 `index.html`，左侧固定导航 + 右侧多视图切换。
> 本文档用于团队内部分享，Mermaid 流程图可在支持 Mermaid 的编辑器（VS Code、语雀、飞书、GitHub）中直接渲染。

---

## 一、整体导航结构

左侧导航分三个分组，共 8 个主视图。

```mermaid
flowchart LR
    Admin["管理端控制台"]

    Admin --> G1["总览"]
    Admin --> G2["课程与教研"]
    Admin --> G3["园务管理"]

    G1 --> Dashboard["数据看板"]
    G1 --> Review["审核中心<br/>（角标：待审核总数）"]

    G2 --> Library["资源与案例"]
    G2 --> Tasks["任务管理"]
    G2 --> Assessment["测评数据"]

    G3 --> HomeSchool["家园共育数据"]
    G3 --> Org["组织管理"]
    G3 --> Content["内容发布"]
```

## 三、审核中心（核心枢纽）

四个并排 Tab，每个 Tab 带待审数量角标。审核通过后内容才在教师端 / 家长端正式生效。

```mermaid
flowchart LR
    Review["审核中心"]

    Review --> T1["资源 Tab"]
    Review --> T2["案例 Tab"]
    Review --> T3["教师资料 Tab"]
    Review --> T4["研修反馈 Tab"]

    T1 --> RC["资源 / 案例审核"]
    T2 --> RC
    RC --> RCView["查看详情<br/>分类 衣食住行艺 / 五大领域 · 附件 · 简介"]
    RC --> RCPass["通过 → 自动入库并发布至资源库 / 案例库"]
    RC --> RCReject["驳回 → 通知教师修改"]

    T3 --> PF["教师个人档案修改审核<br/>来源：教师端 教研培训 → 个人档案"]
    PF --> PFView["查看变更项<br/>履历 / 职称 / 学历 / 新增奖项"]
    PF --> PFFiles["审核附件<br/>学历证书 / 能力证书 / 专业奖项"]
    PF --> PFPass["通过 → 写入教师个人档案"]
    PF --> PFReject["驳回 → 通知补充材料"]

    T4 --> FB["研修反馈审核<br/>来源：历史研修详情页"]
    FB --> FBView["查看反馈全文<br/>教师 · 研修活动 · 内容"]
    FB --> FBPass["通过并公开 → 研修详情页展示"]
    FB --> FBReject["驳回 → 不予公开"]
```

## 十、与教师端 / 家长端的数据联动

管理端不是孤立后台，多数操作会作用到前端（教师端小程序、家长端）。

```mermaid
flowchart TB
    subgraph TeacherApp["教师端"]
        T_Upload["上传资源 / 案例"]
        T_Profile["教研培训 → 个人档案修改"]
        T_Feedback["历史研修 → 研修反馈"]
        T_Todo["待办任务"]
        T_Home["首页推荐"]
        T_Column["资讯栏目<br/>党建 / 通知 / 教研"]
    end

    subgraph AdminConsole["管理端控制台"]
        A_Review["审核中心"]
        A_Library["资源与案例"]
        A_Tasks["任务管理"]
        A_Content["内容发布"]
        A_Data["数据看板 / 测评 / 家园共育"]
    end

    T_Upload -->|提交审核| A_Review
    T_Profile -->|提交审核| A_Review
    T_Feedback -->|提交审核| A_Review

    A_Review -->|通过入库| A_Library
    A_Library -->|推荐| T_Home
    A_Tasks -->|发布| T_Todo
    A_Content -->|发布| T_Column
    A_Review -->|反馈通过| T_Feedback

    T_Upload -.统计.-> A_Data
```
