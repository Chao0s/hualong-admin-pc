# 化龙幼儿园 · 管理端控制台

面向幼儿园管理者（园长 / 各部门负责人）的 PC 端数据管理后台原型。

GitHub 仓库：<https://github.com/Chao0s/hualong-admin-pc>

## 快速预览

直接用浏览器打开 [`index.html`](./index.html) 即可，无需构建、无依赖（单文件、纯前端、内置模拟数据）。

## 功能概览

左侧固定导航，共 9 个视图：

| 分组 | 视图 | 说明 |
|------|------|------|
| 总览 | **数据看板** | 核心 KPI、资源上传趋势、待审核队列、五大领域分布、各班测评完成率 |
| 总览 | **审核中心** | 资源 / 案例 / 教师资料 / 研修反馈审核，以及家庭幼儿资料更正的待审／已处理队列 |
| 课程与教研 | **资源与案例** | 资源库 / 案例库内容管理、分年级推荐覆盖、全资料列排序、年级与学期筛选、上下架 |
| 课程与教研 | **任务管理** | 发布教师任务、跟踪完成进度、催办 |
| 课程与教研 | **测评数据** | 各班五大领域综合评估进度、雷达图对比、导出报告 |
| 园务管理 | **家园共育数据** | 在园时光 / 亲子任务 / 成长档案 / 成长册 完成率 |
| 园务管理 | **组织管理** | 教师 / 班级 / 幼儿 信息维护 |
| 园务管理 | **内容发布** | 党建 / 通知文件 / 教研培训 栏目发布 |
| 园务管理 | **成长册设置** | 选用模板、填 Logo / 封面照片 / 园所介绍 / 园长寄语（可按年级）、新增园所栏目，发布后分发给各班教师 |

本仓库的文档：

| 文件 | 内容 |

| [`docs/adr/`](./docs/adr/) | **本仓库的架构决策记录** —— 只属于管理端的模块边界、视图划分、导航结构等决策。编号从 `0001` 起，与上游 ADR 各自独立 |
| [`decision.md`](./decision.md) | **前端修改记录** —— 原型评审后的每一条修改决定 + 对 backend 的影响。与 `hualong-teacher` / `hualong-parent` 同一约定 |
| [`docs/信息架构.md`](./docs/信息架构.md) | 九个视图的信息架构与三端数据联动图 |
| [`docs/spec-handoff.md`](./docs/spec-handoff.md) | **跨端 canonical 对象注册表** —— 提出任何新 `db_*` 对象之前必须先查这里的第 3、5、6 三节 |
| `docs/backend spec files/` | 九份后端对象规格，一个视图一份 |

**权威来源在后端仓库 `hualong-backend`，本仓库不复制**：

| 文件 | 内容 |
|---|---|
| `docs/ADR-0012-growth-book-content-ownership.md` | 成长册归属：园所填内容 / 我们定版面与美术 / 班级填班级事，含三条判准 |
| `DECISIONS.md` | 已定决议与代价。本仓库相关的是 **E9**（成长册管理端）、**F2**（推荐覆盖与表格行为）、**F3**（园所学期日历） |
| `db/GAPS.md` | schema 与规格之间的已知缺口 |
| `db/spec/screens.tsv` | 三端全部页面的总表，含每页写入的主要数据表 |

## 说明

- 当前为**产品原型**，数据均为演示用模拟数据，操作（审核 / 发布 / 推荐等）仅在前端联动，未接入后端。
- 设计规范沿用教师端：主色青绿 `#189b91`，PingFang 字体，圆角卡片。
- 图表配色经过色盲安全与对比度校验。
